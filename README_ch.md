# 言行（yanxing）

[English](README.md) | **中文**

一个轻量级、零外部进程依赖的 Windows 终端英文打字与听写工具：

-   双栏 / 单栏自适应工作区（终端宽度大于等于 80 列显示练习卡片与词汇队列，小于 80 列自动切换为单栏紧凑模式）；
-   跟打与听写双模式（听写模式隐藏英文拼写，上下条预览仅展示中文释义，单条敲错超过 3 次自动收录错题且不泄露答案；进入错题本后仅支持听写模式并禁用提示键查看答案，本次敲错 1 次即跳过进入下一词，循环往复练习剩余错题，直到全部零错误拼写并清空移出）；
-   中英文等宽字符精确计算与行级增量局部刷新；
-   原生控制台与终端鼠标点击及滚轮支持（自动关闭快速编辑文本选取抢占），全面覆盖顶栏、底栏、弹窗列表、错题管理、完成界面与右侧词汇队列；
-   内置 14 套离线单词库与句子库，支持本地纯文本导入与自定义接口智能出题。

程序以单个纯脚本文件发行，不派生外部子进程，直接调用系统内置语音接口朗读与本地数据库接口持久化学习进度和错题本。

## 快速开始

### 一键安装（推荐，自动配置环境变量）

在终端中运行以下命令：

```powershell
irm https://raw.githubusercontent.com/buer5/yanxing/main/install.ps1 | iex
```

安装完成后即可在任意终端直接输入 `yanxing` 启动。如需卸载：

```powershell
irm https://raw.githubusercontent.com/buer5/yanxing/main/install.ps1 -OutFile $env:TEMP\yx-uninst.ps1; & $env:TEMP\yx-uninst.ps1 -Uninstall
```

### 本地安装或直接运行

```powershell
git clone https://github.com/buer5/yanxing.git
cd yanxing

# 安装到用户目录并自动注册环境变量
.\install.ps1

# 或免安装直接运行源码
.\yanxing.ps1
```

### 常用启动参数

```powershell
yanxing -List                  # 列出所有内置词库与句库
yanxing -b ket2021 -g 1        # 指定词库与分组启动
yanxing -b nce2 -d             # 以听写模式练习新概念 2 句子库
yanxing -f .\notes.txt         # 导入本地文本（支持英文文章或“英文|中文”每行一条）
yanxing -m                     # 静音模式启动
```

## 界面布局与渲染

-   **宽屏模式（80 列及以上）**：左侧为主练习卡片（含进度条、目标词句、音标、中文释义、上一条/下一条中文预览），右侧为本组词汇队列（支持鼠标点击跳词）。
-   **窄屏模式（80 列以下）**：自动隐藏右侧队列，顶栏与底栏按钮自动折行，确保小窗口下所有内容与按钮不被截断。
-   **增量局部刷新**：按中英文实际占宽对齐每一行，仅覆写发生变化的行，避免全屏清屏闪烁。
-   **本地数据持久化**：通过系统内置数据库组件写入用户目录下的独立数据库文件，保存当前词库、分组与错题本。

## 快捷键

| 按键 | 鼠标操作 | 功能 |
| --- | --- | --- |
| `F1` / `Ctrl+B` | 点击顶栏词库按钮 | 切换词库 / 句库 |
| `F2` / `Ctrl+G` | 点击顶栏分组按钮 | 切换分组 |
| `F3` / `Ctrl+M` | 点击顶栏模式按钮 | 切换跟打 / 听写模式 |
| `F4` / `Ctrl+V` | 点击顶栏语音按钮 | 语音朗读开关 |
| `F5` | 点击顶栏错题按钮 | 进入错题本练习 |
| `F6` | 点击底栏乱序按钮 | 随机打乱当前组顺序 |
| `Ctrl+L` | 点击底栏导入按钮 | 导入本地文本文件 |
| `Ctrl+A` | 点击底栏出题按钮 | 调用接口智能生成词库 |
| `Enter` | 点击底栏朗读按钮 | 重听当前发音 |
| `Tab` | 点击底栏提示按钮 | 听写模式下临时显隐拼写 |
| `PgUp` / `PgDn` | 点击底栏上词 / 下词按钮 | 切换上一条 / 下一条 |
| `Esc` / `Ctrl+C` | 点击底栏退出按钮 | 关闭弹窗或退出程序 |
